# Echo Full Deck Assets

This folder contains the organized production tarot image set for Echo Care Web.

## Structure

- `card-back-mystic-editorial.png`
- `major/`
- `minor/cups/`
- `minor/wands/`
- `minor/swords/`
- `minor/pentacles/`

## Counts

- Major Arcana: `22`
- Minor Arcana: `56`
- Total faces: `78`

## Naming

- Major Arcana: `00-the-fool.png` through `21-the-world.png`
- Minor Arcana: `suit-rank-of-suit.png`

## Notes

- All card faces are normalized to `256x410`.
- This directory is the organized full-deck source for future web integration.
- Legacy duplicate card files outside this directory have been removed after all app references were migrated to `full-deck/`.
