## 1. 用户故事

**作为一个** 通过 NFC 戒指进入网页的用户
**我想要** 在首页第一眼感受到安静、私密、有仪式感的陪伴空间
**以便于** 我能自然选择进入每日陪伴或提出一个问题，而不是被复杂功能干扰。

## 2. 验收标准

- [ ] AC 1：首页第一屏有明确 Hero 焦点，用户 3 秒内能理解这是情绪陪伴入口。
- [ ] AC 2：首页保留每日陪伴和问题解牌两条主要路径，但避免做成普通功能菜单。
- [ ] AC 3：首页视觉保持当前黑紫色高级风格，减少不必要的图标、卡片、分割线和说明文字。
- [ ] AC 4：移动端首屏阅读顺序清晰，主要 CTA 不互相抢焦点。
- [ ] AC 5：如调整 NFC 入口承接或埋点，需同步更新相关文档。

## 3. 背景与上下文

首页是戒指触碰后的第一个情绪接触点。当前项目方向不是传统塔罗工具，而是“AI 情绪陪伴，塔罗只是入口”。因此首页应更像 Apple Journal / Calm 的封面体验，而不是功能导航页。
