## 1. 目的

戒指管理工具用于生成和管理戒指链接，支持 NFC 写入和生产运营。

## 2. 目标

- 生成有效的签名链接。
- 支持批量戒指准备。
- 让生成链接可以追溯到戒指 UUID。

## 3. 范围

### 3.1. 范围内

- 管理端链接生成。
- CSV 导出 / 导入流程。
- 新链接格式支持。

### 3.2. 范围外

- 完整角色权限后台。
- 库存管理。

## 4. 技术考量

- 目录：`ring-admin/`
- 批量导入可能需要 Supabase 集成。
- 生成链接必须与公开访问校验逻辑一致。

## 5. 数据 / 业务规则

- 开启访问校验时，戒指链接应包含 UUID 和签名。
- 对已出库 / 已发货戒指，校验端必须兼容历史签名 secret，避免环境变量轮换后旧 NFC 链接整体失效。
- 新链接生成始终使用当前主 `RING_SIGNING_SECRET`；旧 secret 仅用于校验兼容，不再用于签发新链接。

## 6. 待解决问题

- CSV 导出是否应包含生命周期状态？
