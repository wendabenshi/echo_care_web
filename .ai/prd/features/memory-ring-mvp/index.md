## 1. 目的

回忆戒指 MVP 用于探索礼物场景下的 NFC 回忆戒指：一个人可以给另一个人留下语音、文字和照片，对方触碰戒指即可打开。

## 2. 目标

- 验证用户是否愿意购买 NFC 戒指作为私密回忆礼物。
- 第一版足够简单，可以快速开发验证。
- MVP 阶段避免复杂账号体系。

## 3. 范围

### 3.1. 范围内

- 创建回忆页。
- 上传语音。
- 写文字信。
- 上传 1-5 张照片。
- 生成公开回忆链接。
- 可选编辑密码。

### 3.2. 范围外

- MVP 阶段不支持视频上传。
- 不做完整社交 Feed。
- 不做实时通知。
- 不做原生 App。

## 4. MVP 流程

```text
购买者扫码设置二维码
↓
创建回忆
↓
上传语音 / 文字 / 照片
↓
获得回忆链接
↓
戒指写入该链接
↓
接收者触碰戒指
↓
打开回忆页面
```

## 5. 技术考量

- 未来路由：
  - `/memory/setup`
  - `/memory/:id`
  - `/memory/edit/:id`
- Supabase：
  - 元数据存 Postgres
  - 文件存 Storage
- 无账号 MVP 可使用编辑密码。
